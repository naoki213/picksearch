# Everyday Notes

A hand-built static HTML blog generator for publishing articles across any genre —
life, travel, food, technology, health, entertainment, and more. No framework, just
plain Node.js scripts that turn Markdown posts into HTML. A pure blog format with no
affiliate links.

## Setup

```bash
npm install
npm run build   # build content/ into dist/
npm run serve   # preview dist/ at http://localhost:8080
```

## Directory Structure

```
content/
  site.json       # site-wide settings (title, description, production URL, etc.)
  genres.json      # genre list (add an entry here to add a new genre)
  posts/*.md       # posts (Markdown + front matter)
templates/         # HTML templates (layout / home / post / genre / 404 / components)
public/            # static files copied as-is into the output (CSS, JS, images)
scripts/
  build.js         # reads content/ and generates HTML into dist/
  serve.js         # lightweight server for previewing dist/
  new-post.js      # CLI for scaffolding a new post draft
dist/              # build output (gitignored, generated by npm run build)
```

## Writing Posts

To scaffold a new post draft, run:

```bash
npm run new-post -- "Post Title" genreId
```

This creates a Markdown file with front matter in `content/posts/`. Write the body,
then run `npm run build` to turn it into HTML. Repeat this to keep adding posts
across any genre.

### Front Matter Fields

```yaml
---
title: "Post Title"
slug: "url-slug"
description: "A short summary shown in search results and social shares (~160 characters)"
genre: "life"        # a genre ID defined in content/genres.json
tags: ["tag1", "tag2"]
date: "2026-07-01"
---
```

### Adding a Genre

Add `{ "id": "...", "name": "...", "description": "..." }` to `content/genres.json`
and a new genre listing page (`/genre/<id>/`) is generated automatically.

## SEO / Mobile

- Auto-generates `title` / `description` / OGP / Twitter Card / canonical tags for every post, home, and genre page
- Outputs `BlogPosting` structured data (JSON-LD) on post pages and `WebSite` structured data on the homepage
- Auto-generates `sitemap.xml` / `robots.txt` / `feed.xml` (RSS)
- Mobile-first responsive CSS (1 column → 2 columns → 3 columns) with a hamburger menu
- No external fonts or heavy JS libraries — minimal CSS/JS for fast page loads

## Before Going Live

`content/site.json`'s `baseUrl` is a placeholder (`https://example.com`). Once you've
decided on your production domain, update this value and run `npm run build` again
(it's reflected in canonical URLs, OGP tags, sitemap.xml, and feed.xml).
